📖 12-Stage Pipeline Status Vector Legend & Operator Guide

Every audited release is assigned a deterministic 12-stage status vector ([DTHS-MKEX-BRPA]). Each letter position represents a distinct isolation boundary in the supply-chain verification pipeline. Green badges (✓) indicate passed stages, yellow badges (!) indicate governance warnings, and red badges (0) indicate hard failures.

🌐 Group 1: Transport & Network Layer

  • D — DNSSEC & IP Pinning: Asserts transport IP route stability and DNSSEC integrity. (Operator: Check DNS/SOCKS5 proxy).
  • T — TLS Handshake: Validates TLS 1.3 certificate chain against strict Root CA whitelist. (Operator: Verify TLS cert/CA).
  • H — HTTP Transport: Validates HTTP 200 OK & byte-range determinism. (Operator: Check edge cache/CDN).
  • S — Schema Syntax: Parses canonical manifest ordering (SHA256SUMS.asc). (Operator: Inspect manifest formatting).

🔑 Group 2: Key & Governance Layer

  • M — Manifest Signature: Validates OpenPGP or BIP-340 Schnorr signature math. (Operator: Hard BADSIG if failed).
  • K — Declared Key Match: Verifies fingerprint matches in-tree Trust Anchor URL. (Operator: Check Readme.md#pgp key ID).
  • E — Key Expiration: Audits primary/subkey validity timestamps. (Operator: Flags yellow ! if maintainer key expired).
  • X — Key Revocation: Checks CRL / inline 0x20/0x30 revocation certificates. (Operator: Rejects revoked keys).

📦 Group 3: Payload & Blockchain Anchor

  • B — Build & Hash Determinism: Asserts SHA-256 hash match AND ingests WalletScrutiny source-to-binary build attestation (BW-WS-INGEST-v1). (Operator: Hard HASH_DRIFT / build mismatch if failed).
  • R — Freshness TTL: Asserts manifest age ≤ 180 days. (Operator: Flags yellow ! if release mirror stale).
  • P — Peer Mirror Fetch: Multi-vantage secondary fetch. (Operator: Rejects dynamic geofence swaps).
  • A — Bitcoin Chain Anchor: OpenTimestamps Merkle proof anchored to BTC block height. (Operator: Verifies state seal).

⚠️ Declined Candidate Registry: Upstream Release Hygiene Backlog

CLASS B / BRITTLE EXCLUSIONS

The Inverted Trust Arrow Invariant: BinWatch verifies decoupled, deterministic key-artifact pairings without grading on a curve. If a project does not publish standardized, machine-verifiable detached manifests at the release boundary, it is categorized below. We strictly decouple insecure supply-chain hygiene (e.g. naked unsigned checksums, opaque OTA) from non-standard modern cryptographic attestation (hardware multi-sig quorums, Minisign) and container-only web stacks.

⚖️ Passive Conduit Safe Harbor & Limitation of Liability

All advisory references, CVE identifiers, and version thresholds displayed herein are mirrored verbatim and unverified from third-party public databases (including OSV.dev, GitHub Security Advisories, and NVD). BinWatch asserts nothing regarding the security, merchantability, or exploit status of any binary. The absence of an upstream query match indicates solely that no record was returned by the external API at query time; it does not indicate that software is secure, defect-free, or unexploitable.
